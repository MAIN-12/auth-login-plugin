## Deterministic reproduction

Run from the repository root with Python 3. This command verifies the pinned source and license hashes before touching either asset. It preserves entry order and values, including the empty record; it performs no lowercasing, trimming, normalization, filtering, or hand-added expansion.

```bash
python3 - <<'PY'
from pathlib import Path
from urllib.request import urlopen
import hashlib
import json

commit = '49c3b2d1d2481572bd7b0cb5af875a73cdf9d08e'
base = f'https://raw.githubusercontent.com/danielmiessler/SecLists/{commit}/'
raw = urlopen(base + 'Passwords/Common-Credentials/xato-net-10-million-passwords-100000.txt').read()
license_raw = urlopen(base + 'LICENSE').read()
assert hashlib.sha256(raw).hexdigest() == '1472aafa2561df5e3293aee252aee3ca660c12b399a283cf808bb01b39be388b'
assert hashlib.sha256(license_raw).hexdigest() == '3dbdc93d5f8829de0941744841730a09c106d0732e5ae0e98ca1d77be7ded66c'
entries = raw.decode('utf-8').splitlines()
assert len(entries) == len(set(entries)) == 100000
asset = json.dumps(entries, ensure_ascii=True, separators=(',', ':')) + '\n'
assert hashlib.sha256(asset.encode()).hexdigest() == '52ebae33c4c19b503c43daf56c2494c56eb90e4650eda786529782951735ed39'
directory = Path('src/auth/domain')
(directory / 'password-blocklist.json').write_text(asset, encoding='utf-8')
notice = {'asset': 'password-blocklist.json',
          'source': 'https://github.com/danielmiessler/SecLists',
          'commit': commit, 'license': license_raw.decode('utf-8')}
(directory / 'password-blocklist.license.json').write_text(
    json.dumps(notice, ensure_ascii=True, indent=2) + '\n', encoding='utf-8')
print('Verified:', len(entries), 'records;', len(asset.encode()), 'generated bytes')
PY
```

## Updating and verifying

On policy maintenance or new upstream evidence, select a reviewed immutable commit, inspect upstream provenance/license changes, download both sources, and update the pins, hashes, counts, and command together. Do not silently fetch `master` during build or login. Review newly allowed/blocked passwords, run the shared policy tests, and verify the built package contains both JSON files before release. If broader/current compromise screening is required, approve another corpus or privacy-preserving provider separately; this snapshot cannot supply that guarantee.

The generated JSON is one physical line for deterministic compact serialization, **not** one authored line of implementation: its full 100,000-record, 981,882-byte payload must be included in candidate identity and package-size/review accounting. The minimum-length rule rejects the empty record independently. Longer upstream entries such as `Mailcreated5240` are useful blocklist regression cases that would otherwise pass the 15-character minimum.
